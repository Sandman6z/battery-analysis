# xlsx / ndax / XML 三者关系与脉冲电流一致性佐证

## 一、数据流与三者关系

```
XML (测试脚本) → BTS 测试机 → ndax (原始二进制记录) → xlsx (格式转换)
```

- **ndax → xlsx**：`converter.py` 用 NewareNDA 库读取 ndax，电流 mA÷1000→A，工步状态映射（Rest→搁置, CC_DChg→恒流放电, Pulse→脉冲），**无任何数据修改**
- **XML → ndax**：XML 是测试 Profile 下发给 BTS 机的指令，但本次 XML 是旧模板
