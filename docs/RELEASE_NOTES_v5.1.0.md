# v5.1.0 发布说明

日期：2026-10-23。相对 v5.0.3 的 minor 更新，重点恢复 BatteryChartViewer 交互，并统一主窗口派生字段的数据来源。

## 1. 图表导航恢复

继续使用现有 Matplotlib，不引入 PyQtGraph 或其他绘图库、不新增依赖。独立与嵌入数据图共用导航控制器。

| 操作位置 | 左键拖动 | 滚轮 |
|----------|----------|------|
| 绘图区 | 双轴平移 | 以鼠标为锚缩放双轴 |
| 横轴刻度区域 | 仅平移 X | 仅缩放 X |
| 纵轴刻度区域 | 仅平移 Y | 仅缩放 Y |

- 右键点击上述区域恢复本次加载数据后的初始视野。
- 自定义导航写入 Matplotlib 的 Home/Back/Forward 历史，连续缩放不会产生重复起点。
- 原生工具栏 Pan/Zoom 开启时暂停自定义手势，再次点击对应按钮退出模式后恢复；图内按钮辅助轴不会触发导航。
- 过滤和电池显隐继续保留当前视野；重新加载数据重新建立初始视野。
- 导航期间隐藏悬停注释并暂停最近点扫描，普通与 KDTree 延迟回调均检查导航状态。
- 释放、失焦、关闭和重复安装时清理拖动状态、widgetlock 与事件连接。

## 2. 刻度、宿主与提示

- 横纵轴使用自适应刻度，改善缩放后刻度过密/过稀的问题；不再用固定 X 刻度将配置的初始范围扩张到包含全部刻度。
- 嵌入数据图显式安装 Qt 导航工具栏，移除重复创建的 Figure/Canvas；返回值说明与实际五元组接口一致。
- 更新图内帮助文字，明确鼠标手势与工具栏模式互斥。保留现有 File/Help 菜单及默认工具栏，不进行大范围 UI 重写。

## 3. 派生字段只读

- Samples Qty 来自输入文件自动统计；Datasheet Nominal Capacity、Calculation Nominal Capacity、Required Useable Capacity 来自 Configuration → Rules。
- 这四个字段在主窗口只读展示，保留自动更新和文本读取；Tab 顺序跳过派生字段，并更新来源提示。
- 修改容量时请维护 **Tools → Configuration → Rules**，再重新选择适用规格/方法刷新值，不在主窗口覆盖派生值。
- 中英文操作指南同步更新，移除“主窗口容量可手动编辑”的旧描述。

## 4. 自动验证

- 全套自动回归 **1256 项通过**（`QT_QPA_PLATFORM=offscreen`，不含 `tests/manual`）；全仓 Ruff 通过，Mypy 检查 **177 个源文件**无错误。
- `uv sync --all-extras --frozen` 成功，源码、安装包元数据、界面版本封装及构建配置均验证为 **5.1.0**。
- 导航测试覆盖主图/刻度区命中、单轴不变量、跨度、缩放锚点、倒置轴、历史返回、辅助轴隔离、工具栏互斥、释放/失焦/关闭、重复安装及过滤保留视野。
- 菜单/工具栏新增 **16 项行为验收**：Open/Exit/About、Home/Back/Forward、原生 Pan/框选 Zoom、Subplots 布局调整/导出参数/Tight layout/Reset、Customize 选轴与 Apply/OK，以及取消路径。
- 实际生成并检查 PNG、SVG 和 PDF；真实 Qt 文件对话框保存中文路径，验证取消和写入失败提示。
- 本地自动验证不能替代桌面手感或冻结 EXE 验收。PR CI 的测试和构建结果以对应运行记录为准，不因改版本号而宣称发布附件已生成。

## 5. 升级与保持不变

- 软件版本从 **5.0.3 → 5.1.0**，唯一版本源仍为 `src/battery_analysis/_version.py`；包元数据、版本封装和构建读取同一来源。
- 软件版本与报告交付编号独立，不重置报告、校验和账本或成功计数；不自动重算或覆盖旧报告。
- NDAX 输入、配方定档、统计与报告算法不变；v5.0.0 的 [迁移要求](RELEASE_NOTES_v5.0.0.md) 仍适用。
- 升级后重启程序；开发环境执行 `uv sync --all-extras --frozen`，让动态版本元数据刷新。依赖锁文件没有版本化根包字段，本版不升级依赖。
