## 2. 当前告警规则（已实施）

| 情况 | 处理 |
|---|---|
| 普通分析截止档未达到，且该格不是当前型号合格判定所需格 | 不暂停；保留 `None`、报告 `No data`、有效样本数和 JSON 异常明细；日志及分析完成提示汇总缺失槽位/涉及文件数 |
| 任一文件在合格判定所需的电流×电压格缺数据 | 仍需人工明确放行；不补零、不插值、不外推 |
| 配置或实测电流档列表中完全缺少合格判定所需格 | 以 `required_slot_missing` 请求人工确认，显示电流和电压；不偷偷切换到其他档位 |
| NDAX 无法读取、某文件无时间戳或无法分析 | 仍按 `file_error` 请求人工确认；失败文件保留槽位 |
| 整批无有效实测时间戳 | 明确失败，不允许放行生成无可靠日期的报告 |
| 跨日、可识别电流的实测偏差 | 维持记录留痕，不因本次调整增加阻断 |

判定格复用 `build_expectations()`，与报告规则来源一致。型号/构造无法派生时，保守检查最高实测电流×2.25V；没有自行创造 PDF 中不存在的合格阈值。

普通缺失仍沿用原来的 `missing_pulse` 元数据类型，以免破坏已有消费者；GUI 阻断列表不再包含普通缺失。完成提示中的 successful 指产物生成成功，不等于电池 Pass 或已完成全部试验。

## 3. 对照 PDF 已核实的规则

### §6.2.11（第 23–25 页）

第 25 页原文要求：

- 没有单个实测样本的可用容量低于指定期望值：单样本最小值 ≥ 阈值。
- 对应电流/截止电压格的 μ−2σ 必须高于期望值：严格 `>`，不是 `>=`。
- 无特别说明时用最高指定脉冲电流。

当前实现的双条件一致；最小值比较保留 1e-6 浮点容差，统计侧仍严格大于。样本标准差使用 `ddof=1`；只有一个样本时 σ=0 并在备注标注，这是实现边界，不是已证明满足 PDF 的采样充分性。

## 4. 发现但本次未改变的历史边界

1. **实际分析仍用软件配置的 9 档超集。** `PDF_CUTOFF_VOLTAGES` / `PDF_HERMES_CUTOFF_VOLTAGES` 已内置，但主分析的 `listVoltageLevel` 仍来自配置，当前样本是 `2.6,2.5,2.4,2.3,2.25,2.2,2.1,2.0,1.8`。本次不切换 6/7 档，以免改变用户已确认的报告列和图片；不存在从 NDAX 停止电压推导报告档位的行为。
2. **PDF 期望容量依据 datasheet QNOM，当前实现使用 Calculation Nominal Capacity（test_info[9]）。** 两输入值相同时一致；两者不同时，分档和百分比阈值可能不同。百分比阈值还会整 mAh 四舍五入。需单独决定容量口径和精度，不能在放宽告警时悄悄修改。
3. **报告允许缺样本后按剩余有效样本判定。** `counts` 已记录；必需格完全无样本可判为 Incomplete，但部分样本缺失、人工放行后仍可能得到 Pass。缺失未当零是正确的；Pass 不证明所有预期样本均完成。若要强制整个批次样本充分性，需要另定规则并修改结论语义，本次未改。
4. **缺少部分 PDF 必需档位时，报告判定层可能跳过这些格。** 所有期望格都匹配不到时还会使用历史单点回退。此次在分析层新增必需格缺失确认，避免无声通过，但人工放行不会自动重写已有报告判定算法。
5. **温度、老化与配方时序不等于已验收。** PDF 常规期望值注明 +23°C / no Aging，冷冻注明 −20°C；现有报告派生规则并未对所有温度、老化状态重新建阈值。10 次 burst、持续/暂停时间等虽然有常量，也不意味着对每个实测脉冲时序进行了完整合规检查。
6. **报告电池类型历史错误已在用户后续授权后修复。** 原 JSON、ReportCoordinator 和 WordReportWriter 都把型号 `test_info[2]` 传给类型转换函数；匹配失败又默认回退 CoinCell。现统一从提交的 `TestInfo.battery_type`（索引 0，即 GUI Battery Type）读取，用共享 `battery_classifier.battery_type_code()` 序列化。未知类型明确报错，不默认为纽扣电池；不再让各输出按型号自行猜类型。真实样本新 JSON 已验证为 `PouchCell`，既有旧报告不自动改写。

以上并非本次新增故障，不宣称软件已全面符合 PDF。

## 6. 容量字段来源（后续追查）

两个字段不是软件从电池实测自动计算，也不是自动读取厂商 datasheet PDF：

- 规则格式：`型号/成组方式/DatasheetNominalCapacity/CalculationNominalCapacity/RequiredUseableCapacity/CC电流`。
- `ValidationSpecRulesMixin._fill_spec_rule_fields()` 分别把规则索引 2、3 填到两个 GUI 输入框；输入框允许用户编辑。
- 点击分析时，`AnalysisRunner._prepare_test_info()` 把当时 GUI 的值快照为 `TestInfo` 索引 8、9。报告、JSON 审计保留这个提交值。
- 配置示例：`CR2450/1S1P/600/550/380/1.0` 对应 600 与 550mAh；`CP5022121/1S1P/3500/3500/85%/10` 对应两个值均为 3500mAh。
- 百分比 required 的规则换算也使用规则第 4 段（Calculation），不是第 3 段；百分比结果取整。PDF 判定派生使用提交后的 Calculation 值。当前不改变这一口径，只记录两个输入及其差异，避免改变既有结果。
- 规则文件的值是否真正来自厂商 datasheet 需由配置维护者确认；字段叫 Datasheet 不代表程序已自动核验过文件。
- 两个字段不同的直接原因是配置分别存了两个独立值，并且界面允许分别编辑。没有代码把 600mAh 自动测量/折算成 550mAh；也没有证据证明这组历史数值的具体制定原因，不能擅自解释成温度降额、实测容量或厂商保证值。
- 用户确认：缺样本及报告统计/判定语义暂不进一步调整，后续有明确要求再变更；电压超集继续保留。

## 7. 样本缺失的含义与本批覆盖率

本批不是少了 28 个电池，而是 16 只电池的 864 个容量槽位中缺了 28 格。每个电流×电压格独立用有效样本统计，样本数不一定都是 16。

| 槽位 | 缺失数 | 有效样本数 |
|---|---:|---:|
| 60mA / 1.8V | 1 | 15 |
| 30mA / 1.8V | 4 | 12 |
| 15mA / 2.0V | 1 | 15 |
| 15mA / 1.8V | 8 | 8 |
| 6mA / 2.1V | 1 | 15 |
| 6mA / 2.0V | 1 | 15 |
| 6mA / 1.8V | 12 | 4 |

当前合格判定格 150mA / 2.25V 无缺失，有效样本 16。上述缺失不进入该格统计，因此不会经这条路径改变其判定；但其他缺格自身的均值、标准差、箱线图只代表剩余样本，不能推断缺失样本容量。缺失可能与放电特性相关，不保证随机；不能把减少样本后的统计理解为完整批次统计。

## 8. 非阻断异常的日志/过程记录

- 原始 `Info_Plot.json.anomalies` 保留，继续兼容旧读取器。
- 新增 `analysis_audit.input_context`：提交的电池类型及规范编码、型号、两种容量、当前阈值计算口径、声明样本数/文件数、profile 校验结果。
- 新增 `analysis_audit.classification`：每条异常的具体内容、分类、是否要求确认；包括普通档缺失、判定档缺失、文件失败、跨日、电流偏差，以及两个容量输入不同。
- 新增 `analysis_audit.confirmation`：是否无需确认、人工允许，或未连接确认回调。拒绝时不产出报告，但应用日志记录拒绝及全部异常。
- 新增 `analysis_audit.slot_sample_counts`：各电流/电压格的 expected 文件数与 valid 样本数；valid 与当前统计一样排除 None 和 0，不改变现有数据处理。
- 日志逐项写出分类、文件/电流/电压/原因，并写缺格的有效/预期样本数；不记录整份原始逐行测量，避免日志爆量。
- 这些记录覆盖程序当前检测到的异常，不意味着已检测 PDF 所有试验异常或自动验证全部实测时序。

## 9. 电池应用寿命资料参考（建议，不进入判定代码）

参考厂商原件：Energizer《Lithium Coin Handbook and Application Manual》：
https://data.energizer.com/pdfs/lithiumcoin_appman.pdf

- PDF 第 2 页：应用可用容量取决于负载电流和截止电压；高于 2V 的设备截止电压可能使电池仍有容量未被设备使用。
- 第 3 页：高脉冲负载必须考虑脉冲期间负载电压（CCV），不能只依据平均电流估计应用寿命。
- 第 4 页：低温通常降低设备中的电压表现与运行时间。
- 第 5 页：负载和占空比影响放电过程中的内阻。
- 推论：不同脉冲档未达到同一电压点，不等于没有脉冲或容量为零。保留实测曲线、截止条件、有效样本数比填零/无依据外推更合适。
- 边界：手册没有给出本软件的缺失数据统计政策，也没有据此验证 CP5022121 的寿命模型；纽扣电池资料不能直接当作软包电池的定量模型。当前不新增寿命估算、缺失值插补或判定算法。
