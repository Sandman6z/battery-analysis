# v5.1.5 发布说明

## 版本与范围

本次是 **5.1.5 补丁版**，主题是**内部重构与遗留功能退役**：先按调用链和相似度审计全量函数，再统一业务规则、修复校验不一致，最后删除已断开的功能链。不新增用户功能，不修改分析算法、容量判定、NDAX 主输入、异常人工确认规则、报告交付版本或历史账本。

软件版本与报告交付编号独立；已有报告、SHA256 成功计次和账本不自动改写。

详细梳理记录：

- [函数审计与候选结论](function-audit/README.md)
- [输入校验与 NDAX 扫描功能梳理](function-audit/functional-review.md)
- [遗留功能退役台账](function-audit/retired-features.md)

## 实现去重

- 后台任务派发统一走 `TaskManager.run_async`（先连接回调再提交，保证快速任务不丢信号）；数据处理器与版本管理器旧入口改为委托。
- 状态栏切换、Word 模板占位符构建、设备信息点号键读取各保留一份实现，旧入口委托同一实现。
- 删除初始化步骤中仅 `return True` 的默认 `can_execute` 覆盖，直接继承基类。

## 功能统一与行为修复

### 输入校验

- 业务规则统一在 `InputValidator`；删除界面侧第二套字段检查（旧字段表、标签重置、组合框/文本框非空判断等）。
- Test Profile 保持可选：此前界面提示可选、运行前有无 Profile 确认流程，但旧检查把空 Profile 拦住，实际入口无法走到确认；现已对齐。
- Reported By、Version 仍必填，纳入唯一必填表。
- 输入/输出路径必须是已存在的目录；此前存在的普通文件会被当作有效路径。
- 计算容量/要求可用容量的实时提示与运行前正整数校验一致（0、负数、小数、非法文本提前高亮）。
- 共享规格标签按所有关联字段错误取并集，不再被另一个无错误字段清除红色。
- 必填字段纯空格按空处理；路径校验保留原值，不改写用户输入。
- 纯校验失败时状态栏展示具体字段错误，成功时清除旧高亮。
- NDAX 运行前预检、后台读取保护、冷冻温度确认等阶段保护保留；路径在实时提示通过后运行时仍重新验证。

### NDAX 文件发现

- 转换预览、批量转换、元数据扫描、校验和与分析共用 `scan_sorted_ndax`：非递归、扩展名不区分大小写、只选实际文件、按通道数字自然排序（通道 2 在通道 10 前）。
- 以 `.ndax` 结尾的目录不再进入文件列表；转换接口的返回类型和“目录不存在返回空列表”兼容行为保留。

## 遗留功能退役

| 退役项 | 原因 |
|---|---|
| `ValidationService` / `ValidationController` | 字段索引、化学体系电池分类、浮点容量范围与当前 TestInfo/NDAX 契约不符，且不在实际分析链上 |
| 五个占位命令（计算电池/分析数据/生成/导出报告/批量处理）及 Presenter | 最终仅输出日志或 Ready，未执行对应业务；另一套必填/Barcode 校验无生产调用方 |
| 十个隐藏菜单动作（New/Open/Save/Save As、Undo/Redo、Export Report、Calculate Battery、Generate Report、Batch Processing） | 不在可见菜单且无有效处理器；实际分析、报告功能不受影响 |
| 历史 Designer UI（`.ui`、`ui_main_window.py`）、未使用的 `PyQt6UIFramework`、Pyuic6 任务、构建强制导入 | 真实界面由 UIBuilder + BatteryAnalysisTab 构建，无生产导入 |
| 旧 `ResourceManager` | 无生产调用方；当前转换使用 `concurrency_policy` |
| 旧通用 Excel 摘要/校验链（`excel_processor`、`excel_validator`、`scan_sorted_xlsx`） | 仅内部互引和测试；保留 XLSX 读取器、NDAX→XLSX、Excel 报告写入 |
| 旧逐格 `numeric_utils` | 生产已不用；统计集中在 `statistics_utils`，保留独立 NumPy 参考值对照测试 |
| 空壳方法与未使用异常类型 | 空设置保存/加载、空刷新回调、旧重复恢复对话框、未抛出/捕获的分层异常 |

配套清理：服务容器节点 7→5、初始化步骤 12→11、启动命令 6→1；对应快捷键、信号连接、模块导出、构建引用和旧测试同步移除。旧内部 Python API 不再保留兼容空壳，二次开发需更新导入。

## NDAX 目录选择引导

- 附带一次性的 NDAX 目录选择引导：首次启动高亮真实 Open 按钮，说明直接选择包含原始 NDAX 的文件夹，无需先转 Excel；关闭后按 QSettings（`onboarding/ndax_direct_folder_v1`）记忆不再出现。
- 不替换按钮原有动作；支持 Escape 关闭、跟随主题变化、随祖先控件移动重新定位；含中英文翻译条目。
