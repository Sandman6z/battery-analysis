# Battery Analysis Tool

欢迎使用 Battery Analysis Tool **v5.1.1** 文档站点。主分析已切换为 NDAX 原生读取，不再依赖中间 Excel；软件版本与报告交付编号独立。

## 功能特性

- 电池数据分析与可视化，Viewer 刻度区单轴拖动、滚轮缩放及视图历史
- 样本数量与容量派生字段只读展示，容量规则集中维护
- 原始 NDAX 直读，Step.xml 配方定档与 Profile 对照
- 普通缺失自动继续、必需缺失人工确认、异常分类与有效样本数审计
- 手动报告版本校验、输出防覆盖和成功后计次
- 保留独立 NDAX→Excel 导出与 Excel/Word/CSV/JSON/PNG/SVG 报告
- 脉冲识别与匹配
- 批量处理与报告生成
