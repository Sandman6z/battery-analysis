```python
def _battery_line_indices(battery_index, current_level_num):
    """返回属于指定电池的所有曲线索引。

    曲线按电池主序构建（figure_builder 中 line = b*current_level + c），
    因此电池 b 的曲线索引区间为 [b*level, (b+1)*level)。
    """
    start = battery_index * current_level_num
    return range(start, start + current_level_num)
```

### Task 6: 修复 Gitee 同步 workflow 的 token 泄漏

`sync-to-gitee.yaml` 把 `${env:GITEE_USERNAME}:${env:GITEE_TOKEN}` 直接拼进 remote URL（line 61），随后 `git remote -v`（line 65）把它打印到 CI 日志——凭据泄漏。改为：remote URL 不含凭据，推送时经 `http.extraheader` 提供 base64 认证头。

```yaml
    - name: Add Gitee remote repository
      if: steps.check_secrets.outputs.secrets_configured == 'true'
      run: |
        # 获取仓库名称
        $repoName = $env:GITHUB_REPOSITORY.Split('/')[1]

        # 移除现有的 gitee 远程仓库（如果存在），忽略不存在时的报错
        git remote remove gitee 2>$null | Out-Null
        if ($LASTEXITCODE -ne 0) { Write-Output "No existing gitee remote to remove" }

        # remote URL 不含凭据（token 仅经 http.extraheader 传递，避免 git remote -v 泄漏）
        $giteeRepoUrl = "https://gitee.com/${env:GITEE_USERNAME}/${repoName}.git"
        git remote add gitee $giteeRepoUrl

        # 只展示 remote 名称，不打印 URL（URL 不含凭据，但为谨慎不输出完整地址）
        git remote show -n gitee 2>$null | Select-Object -First 1 | ForEach-Object { "Gitee remote configured for $repoName" }
      shell: powershell
```

- [ ] **Step 2: 修改 "Push to Gitee" 步骤，推送经 http.extraheader 认证**

在 `sync-to-gitee.yaml` 的 "Push to Gitee" 步骤（line 68 起）的 `run: |` 第一行之后、推送命令之前，注入 base64 认证头，并把每个 `git push` 改为带 `-c http.extraheader=`。修改后的步骤：

```yaml
    - name: Push to Gitee
      if: steps.check_secrets.outputs.secrets_configured == 'true'
      run: |
        Write-Output "正在同步到 Gitee..."
        Write-Output "触发事件: $env:GITHUB_EVENT_NAME"
        Write-Output "引用: $env:GITHUB_REF"

        # 凭据仅经 http.extraheader 传递，绝不进入 remote URL
        $auth = [Convert]::ToBase64String([Text.Encoding]::ASCII.GetBytes("${env:GITEE_USERNAME}:${env:GITEE_TOKEN}"))
        $pushArgs = @("-c", "http.extraheader=AUTHORIZATION: basic $auth", "push", "gitee")

        # 根据触发事件确定要推送的内容
        if ($env:GITHUB_EVENT_NAME -eq 'push') {
          if ($env:GITHUB_REF_TYPE -eq 'tag') {
            $tagName = $env:GITHUB_REF_NAME
            Write-Output "推送标签 $tagName 到 Gitee..."
            git @pushArgs "refs/tags/$tagName"
          } else {
            $branchName = $env:GITHUB_REF_NAME
            Write-Output "推送分支 $branchName 到 Gitee..."
            git @pushArgs "$branchName"
          }
        } elseif ($env:GITHUB_EVENT_NAME -eq 'release') {
          $releaseTag = $env:GITHUB_REF_NAME
          Write-Output "推送 Release 标签 $releaseTag 到 Gitee..."
          git @pushArgs "refs/tags/$releaseTag"

          Write-Output "推送 main 分支到 Gitee..."
          git @pushArgs "main"
        } else {
          $currentBranch = git branch --show-current
          Write-Output "推送当前分支 $currentBranch 到 Gitee..."
          git @pushArgs "$currentBranch"
        }
      shell: powershell
```
