# 电池分析工具 · 快速操作指南

> 适用于 BOEDT Battery Analysis Tool **v5.1.2**。
>
> 本工具直接分析 NEWARE 原始 **NDAX 数据**，自动生成箱线图、Excel 结果表、Word 报告、CSV 和 JSON。主分析无需先转换成 Excel。
>
> 本版更新操作指南与 Wiki 帮助入口，见 [v5.1.2 发布说明](RELEASE_NOTES_v5.1.2.md)；[v5.1.1 的 Windows EXE 启动修复](RELEASE_NOTES_v5.1.1.md)继续适用。
>
> 本版图表交互及只读字段变更见 [v5.1.0 发布说明](RELEASE_NOTES_v5.1.0.md)；NDAX 迁移注意事项见 [v5.0.0 发布说明](RELEASE_NOTES_v5.0.0.md)。

> 对比之前的版本，去掉了`setting.ini`文件，配置都在软件中完成（Tools——Configuration）
> 如需导出原始数据为 Excel，请打开 **工具 → NDAX 转换器**（位于 `BatteryChartViewer` 下方）。转换在独立窗口中运行，结果保存到所选目录同级的 `2_xlsx`，不会更改主分析配置，也不是主分析前置步骤。

## 一、最快上手：三步走

| 步骤 | 操作 | 软件自动帮你做的事 |
|------|------|------------------|
| 1 | **选择 `1_ndax` 输入目录，或选择 Test Profile XML**（选填） | 同级路径互相带出，见下方 **Tips 1** |
| 2 | 点击绿色 **Run** | 校验→计算→绘图→生成报告，全程自动 |
| 3 | 完成后点击 **"打开报告"** / **"打开路径"** | 一键直达结果 |

- 常规情况下，选择 XML 后确认 `1_ndax` 原始数据、自动带出的信息及报告版本，再点 Run；也可以直接选 NDAX 目录，无 XML 时按说明确认使用内嵌配方。
- **如果有新增配置，比如电池信息、电池厂家等，请到configuration中修改，在里面新增一条或新增一行**

## 二、省事小 Tips（重点）

### Tips 1. 选 NDAX 目录或 XML，路径都能自动带出

`1_ndax` 与 `4_test profile` 通常位于同一项目目录下，两种入口均可使用：

- **选择 `1_ndax`**：自动查找同级 `4_test profile` 中的 XML；多个 XML 时由你选择，取消则留空。未找到时 Profile 留空并在状态栏提示，首次无 Profile 运行时按提示确认使用 NDAX 内嵌配方。
- **选择 Test Profile XML**：自动验证 XML（文件名规范、内容完整，编码自动兼容 UTF-8/GBK），并定位同级 `1_ndax`，不再读取 `2_xlsx`。
- **输出路径固定为** 同级 `3_analysis results`，不存在时自动创建；只读显示，不再提供选择按钮或允许自定义目录。
- 切换项目时重新确定 Profile 和路径，不沿用上一个项目的配置。
- **温度自动检测**：读取所选 NDAX 内部 `TestInfo.xml` 的 `TestInfo@StepName`，含 `Freezer`（忽略大小写）→ 冷冻配方，否则 → 常温配方；外部 XML 文件名不参与判断
- 按 NDAX 输入校验和自动建议报告版本；允许手动选择不低于最高版本且未占用的编号（见 Tips 9）
- 如果你是新增人员，直接在名字框里面输入你的名字即可

> 💡 Test Profile 是选填的校验文件，不是分析数据源；只准备 `1_ndax` 也能开始分析。XML 与 NDAX 内嵌档位不一致时会提示差异；确认继续仍使用 NDAX `Step.xml`，不会改用外部 XML 档位。

---

### Tips 2. 选完目录，表单自动填好

设置输入路径后，软件在**后台线程**扫描目录下的 `.ndax` 文件并检查配方，自动带出：

- **样本数量** = 输入 NDAX 文件数，只读展示（不是各容量格的有效样本数）
- 从**第一个文件名**自动解析带出：
  - 构造方式（Construction Method）
  - 规格型号（Specification Type，自动匹配最长的那个）
  - 规格方法（Specification Method）
  - 制造商（Manufacturer）
  - **批次日期码**（兼容 `DC2604`、`DC(2604)`、`DC (2604)` 三种写法）
  - **恒流电流**（从 `mA,xxmA` 写法中提取）
- **主分析脉冲电流**从 NDAX 内嵌 `Step.xml` 读取，不再按文件名或配置表猜测；同批文件的档位和顺序必须一致。

> 💡 文件名用于非档位信息，不能覆盖 Step.xml。型号未配置会提示补规则；成组方式未识别而默认 `1S1P` 时会倒计时提示，请检查，不代表已确认文件本身声明了该方式。

---

### Tips 3. 容量、温度自动判定

选择「规格型号 + 规格方法」后，软件按配置里的 **Rules 规则**自动带出：

- **标称容量**、**计算容量**、**可用容量**（绝对值，如 `380`；或百分比，如 `80%` = 计算容量 × 80%；或构造相关双百分比 `85%|75%` = 螺旋/叠片，按所选构造方法换算，对齐 BatteryQualityRequirements_v2.3 §7.1.1）
- 自动匹配**电池类型**（如选 CR2450 → Coin Cell）
- **温度类型仅由 NDAX 内嵌 `StepName` 自动带出**，不可手动切换；容量规则不再决定温度。冷冻标称温度默认 −20°C，可编辑，但不是实测温度。
- 缺失或无法读取 `StepName` 时不默认常温；同批 NDAX 温度类型或脉冲档位不同则拒绝分析。分析始终使用 NDAX `Step.xml` 的实际配方档位（例如低温样本为 15/13/7.5/3mA）。

> 💡 冷冻温度设为 0°C 时点 Run 会弹确认框，防止误填。
>
> 两个 nominal capacity 都是规则自动填入的独立参数，不是从实测计算或自动读取厂商 PDF。样本数量和三项容量在主窗口只读展示；容量修改请到 **Tools → Configuration → Rules**，再重新选择对应规格/方法以刷新派生值。比如 CR2450 现有规则为 600/550mAh，CP5022121 为 3500/3500mAh；当前计算仍按 Calculation 容量口径，两值不同会记录。输出类型统一使用提交的 Battery Type，未知或空类型明确报错，不默认成 Coin Cell。

### Tips 4. 首次打开零配置

- 首次运行自动在 `%APPDATA%\battery-analysis\config.json` 创建默认配置
- 电池类型、规格型号、制造商、规格方法、脉冲电流、截止电压、
  测试地点、测试人员、设备型号与固件版本等**全部预置**
- 旧版本配置自动迁移、自动做配置完整性校验
- 通用界面配置有默认值及迁移机制；**这不代表报告数据可以兜底**：未知电池类型、无可靠配方或整批无时间戳必须报错，不猜测参数
- 之后每次启动自动加载，无需重新设置

---

### Tips 5. 测试信息自动保存、自动带出

- **Test Information 表格**里的内容（设备、软件版本、测试人员、环境温湿度等）点 Run 时自动保存到配置
- 下次打开自动带出上次填写的内容
- 下拉框（测试地点、测试人员、Reported By）自动从配置加载
- **选择「测试地点」→ 整张设备信息表自动填好**：测试设备、BTS 服务器/客户端/分析软件版本、中位机与测试单元型号/硬件版本/序列号/固件，全部按测试地点预置在配置中，一键带出
- 编辑完配置对话框关闭后，之前选中的电池类型、制造商、测试地点、测试人员等**自动恢复原选中值**，不会丢失

---

### Tips 6. 分析完成一键直达

- 分析完成后弹窗提供 **"打开报告"** / **"打开路径"** / **"确定"**
- 自动匹配当前版本的 Word 报告；找不到时自动打开**最新的**一份
- 报告文件自动按规则命名：`制造商_规格_DC批次_TD日期_v版本.docx`
- **Word 模板自动选择**：按电流等级数量（≤4 或 >4）自动选用对应模板
- 输出目录自动创建（`日期_v版本` 子目录），并自动生成：
  箱线图和负载电压曲线(PNG/SVG)、Result/Sample Excel、Word、CSV、JSON（含异常及过程审计）
- 报告支持 Pass / Fail / Incomplete。缺失容量显示 `No data`，空统计显示 `No data (n=0)`；生成成功不代表电池合格或试验完整

---

### Tips 7. 语言、主题自动记住，窗口自动适应

- **语言**：首次启动自动检测系统语言；手动切换后自动记住，下次启动保持
- **窗口**：每次启动自动**居中、自适应屏幕尺寸**（小屏自动出现滚动条、窗口可自由拉伸/最大化）
- **主题 / 字体大小**：在 Preferences 中设置后自动记住

---

### Tips 8. 实时校验，填错了立刻知道

- 必填项为空 / 路径不存在 / 版本号格式错误时，对应输入框**变红**并在状态栏提示
- 校验通过后状态栏显示 `status:ok`，Run 按钮正常可点
- 出错文件会在弹窗中列出详细原因，方便排查

---

### Tips 9. 报告版本可手动选择，但不能覆盖旧交付

- 软件 `5.1.2` 与报告 `4.0/4.1` 等编号独立。
- 报告版本须不低于当前自动基线和已有交付最高版本，且尚未使用；最低为 `4.0` 时不能填 `1.08`。
- 按数字分段比较，`4.01` 与 `4.1` 视为同一版本；换测试日期也不能重复使用旧编号。
- 手动版本在成功后保留；只有全部必需交付物检查成功才增加成功次数，失败/取消不计成功。
- 输入变化或从旧 Excel 流程升级后先刷新 NDAX 校验和；不手工删除 `SHA256.csv` 来绕过限制。

### Tips 10. 缺失分级，不再被普通截止档频繁打断

- 普通非判定格缺失自动继续，在完成提示汇总，不补零、不插值、不外推。
- 必需判定格缺失或可分析阶段的单文件失败，仍需阅读可滚动详情并两次确认；默认停止。
- 配方损坏、同批档位不一致在运行前报错，不靠放行绕过；整批无有效实测时间戳直接失败。
- 部分样本缺失后放行，报告仍可能基于剩余样本得到 Pass；目前保留这一判定口径。

### Tips 11. 去哪里查没有弹窗的异常

- `Info_Plot.json`：原始 `anomalies`、文件/格状态，以及 `analysis_audit` 中的输入来源、容量依据、异常分类/确认状态、必需判定格与各格有效/预期样本数。
- 应用日志：`%LOCALAPPDATA%\BatteryAnalysis\logs`，记录非阻断异常和运行各阶段错误。
- 跨日按最早有效实测采样时间命名并留痕；实测电流偏差不会偷偷改变配方档位。

### Tips 12. 旧结果不会自动删掉重跑

- 同名临时目录、最终目录或 Word 已存在会拒绝覆盖，请先核实旧文件，再选未使用版本。
- 正常失败/取消只清理本次新建产物；硬崩溃残留不自动恢复或删除。
- 升级前备份报告和账本，并重启应用；旧窗口不会热加载新代码。旧 XLSX 哈希保留但不等于新 NDAX 哈希。
- 报告截止电压仍用软件配置超集，不用 NDAX 的停止/保护电压替代。

---

### Tips 13. BatteryChartViewer 缩放与拖动

通过 **Tools → BatteryChartViewer** 打开；查看已有分析结果时，使用 Viewer 的 **File → Open** 选择包含 `Info_Image.csv` 的数据目录。

| 鼠标位置 | 左键拖动 | 滚轮 |
|----------|----------|------|
| 绘图区 | 双轴平移 | 以鼠标位置为锚缩放双轴 |
| 横轴刻度区域 | 仅平移 X 轴 | 仅缩放 X 轴 |
| 纵轴刻度区域 | 仅平移 Y 轴 | 仅缩放 Y 轴 |

- 在上述区域右键点击可恢复初始视野；过滤/电池显隐切换保留当前视野，重新加载数据建立新的初始视野。
- **Home / Back / Forward** 可导航视图历史；**Pan / Zoom** 是原生工具栏模式，开启时暂停以上自定义手势，再次点击相应按钮退出后恢复。
- **Subplots** 调整布局；**Customize** 编辑图表参数，多轴选择框中请选择主图而非按钮辅助轴；**Save** 保存图像，支持 PNG/SVG/PDF 等格式。
- **File → Exit** 关闭 Viewer；**Help → About** 显示版本信息。主窗口 View 菜单的字号缩放不是图表坐标缩放。

## 三、菜单与快捷键

- **Tools → Configuration**：管理电池配置、测试配置、设备信息（可增删规格、制造商、测试人员等）
- **Preferences**：语言、主题、字体大小、自动保存、退出确认等
- **Help → User Manual（帮助 → 用户手册）**：打开 [GitHub Wiki](https://github.com/Sandman6z/battery-analysis/wiki)，选择中文或英文操作指南（需要联网）

## 四、常见问题

| 问题 | 解决 |
|------|------|
| 提示"输入路径没有数据" | 确认 `1_ndax` 或手选输入目录下有原始 `.ndax`；只有 Excel 不能运行新版主分析 |
| 输出目录无法创建 | 输出固定为输入目录同级的 `3_analysis results`，自动创建；检查该位置的写入权限，不能手动另选输出目录 |
| 版本号不对/校验和未就绪 | 等待或刷新 NDAX 校验和；可手动填不低于最高版本且未占用的编号，不要删账本 |
| 界面显示不全 | 窗口可自由拉伸、最大化；小屏会自动出现滚动条 |
