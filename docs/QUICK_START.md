# 电池分析工具 · 快速操作指南

> 适用于 BOEDT Battery Analysis Tool
>
> 本工具用于分析 NEWARE 电池测试系统导出的 **Excel 数据**，自动生成箱线图、Excel 结果表、Word 报告和 CSV 汇总。

> 对比之前的版本，去掉了`setting.ini`文件，配置都在软件中完成（Tools——Configuration）
> 与版本共同发布的还有批量转换软件`ndaxConverter`，与软件本体同一个下载地址

---

## 一、最快上手：三步走

| 步骤 | 操作 | 软件自动帮你做的事 |
|------|------|------------------|
| 1 | **选择 Test Profile**（Browse 到 XML 测试配置文件） | 见下方 **Tips 1** |
| 2 | 点击绿色 **Run** | 校验→计算→绘图→生成报告，全程自动 |
| 3 | 完成后点击 **"打开报告"** / **"打开路径"** | 一键直达结果 |

- 绝大多数情况下，你只需要**选择一个 XML 文件、点一次 Run**，剩下都交给软件自动完成。
- **如果有新增配置，比如电池信息、电池厂家等，请到configuration中修改，在里面新增一条或新增一行**

## 二、省事小 Tips（重点）

### Tips 1. 选一个 XML，路径全部自动带出

选择 **Test Profile (XML)** 后，软件自动完成：

- 自动验证 XML（文件名规范、内容完整，编码自动兼容 UTF-8/GBK）
- **输入路径自动指向** 同级的 `2_xlsx` 文件夹
- **输出路径自动指向** 同级的 `3_analysis results` 文件夹（不存在时自动询问创建）
- **温度自动检测**：文件名含 `Freezer` → 冷冻温度；否则 → 常温
- 版本号自动计算并填入
- 如果你是新增人员，直接在名字框里面输入你的名字即可

> 💡 输出目录不存在时会弹窗问你是否创建，选"是"即可，不用手动建文件夹。

---

### Tips 2. 选完目录，表单自动填好

设置输入路径后，软件在**后台线程**扫描目录下所有 `.xlsx` 文件（界面不卡顿），并自动带出：

- **样本数量** = 目录下 Excel 文件数
- 从**第一个文件名**自动解析带出：
  - 构造方式（Construction Method）
  - 规格型号（Specification Type，自动匹配最长的那个）
  - 规格方法（Specification Method）
  - 制造商（Manufacturer）
  - **批次日期码**（兼容 `DC2604`、`DC(2604)`、`DC (2604)` 三种写法）
  - **脉冲电流**（从 `(15-6mA)` 这类写法中提取）
  - **恒流电流**（从 `mA,xxmA` 写法中提取）

> 💡 文件名里写清楚规格/批次/电流，选择后表单几乎全自动填好，只需确认。

---

### Tips 3. 容量、温度自动判定

选择「规格型号 + 规格方法」后，软件按配置里的 **Rules 规则**自动带出：

- **标称容量**、**计算容量**、**可用容量**（= 计算容量 × 要求的百分比，如 80%）
- 自动匹配**电池类型**（如选 CR2450 → Coin Cell）
- 按可用容量自动判定**温度类型**：
  - `280` → 自动切到 **Freezer -20°C**
  - `380` → 自动切到 **常温**

> 💡 冷冻温度设为 0°C 时点 Run 会弹确认框，防止误填。

---

### Tips 4. 首次打开零配置

- 首次运行自动在 `%APPDATA%\battery-analysis\config.json` 创建默认配置
- 电池类型、规格型号、制造商、规格方法、脉冲电流、截止电压、
  测试地点、测试人员、设备型号与固件版本等**全部预置**
- 旧版本配置自动迁移、自动做配置完整性校验
- 配置项缺失/为空时自动使用**内置兜底值**，不会因配置损坏导致界面空白
- 之后每次启动自动加载，无需重新设置

---

### Tips 5. 测试信息自动保存、自动带出

- **Test Information 表格**里的内容（设备、软件版本、测试人员、环境温湿度等）点 Run 时自动保存到配置
- 下次打开自动带出上次填写的内容
- 下拉框（测试地点、测试人员、Reported By）自动从配置加载
- **选择「测试地点」→ 整张设备信息表自动填好**：测试设备、BTS 服务器/客户端/分析软件版本、中位机与测试单元型号/硬件版本/序列号/固件，全部按测试地点预置在配置中，一键带出
- 编辑完配置对话框关闭后，之前选中的电池类型、制造商、测试地点、测试人员等**自动恢复原选中值**，不会丢失

---

### Tips 6. 分析完成一键直达

- 分析完成后弹窗提供 **"打开报告"** / **"打开路径"** / **"确定"**
- 自动匹配当前版本的 Word 报告；找不到时自动打开**最新的**一份
- 报告文件自动按规则命名：`制造商_规格_DC批次_TD日期_v版本.docx`
- **Word 模板自动选择**：按电流等级数量（≤4 或 >4）自动选用对应模板
- 输出目录自动创建（`日期_v版本` 子目录），并自动生成：
  箱线图(PNG/SVG)、Excel 结果表、Word 报告、CSV 汇总

---

### Tips 7. 语言、主题自动记住，窗口自动适应

- **语言**：首次启动自动检测系统语言；手动切换后自动记住，下次启动保持
- **窗口**：每次启动自动**居中、自适应屏幕尺寸**（小屏自动出现滚动条、窗口可自由拉伸/最大化）
- **主题 / 字体大小**：在 Preferences 中设置后自动记住

---

### Tips 8. 实时校验，填错了立刻知道

- 必填项为空 / 路径不存在 / 版本号格式错误时，对应输入框**变红**并在状态栏提示
- 校验通过后状态栏显示 `status:ok`，Run 按钮正常可点
- 出错文件会在弹窗中列出详细原因，方便排查

## 三、菜单与快捷键

- **Tools → Configuration**：管理电池配置、测试配置、设备信息（可增删规格、制造商、测试人员等）
- **Preferences**：语言、主题、字体大小、自动保存、退出确认等
- **帮助 → 用户手册**：查看本说明文档

## 四、常见问题

| 问题 | 解决 |
|------|------|
| 提示"输入路径没有数据" | 确认 `2_xlsx` 文件夹下有 `.xlsx` 文件（排除以 `~$` 开头的临时文件） |
| 提示输出目录不存在 | 在弹窗中点"是"自动创建，或手动选择已有目录 |
| 版本号不对 | 版本号由数据内容自动决定，不要手动改；确认输入/输出路径正确 |
| 界面显示不全 | 窗口可自由拉伸、最大化；小屏会自动出现滚动条 |
